# searat.nar decompiled

The completely decompiled files of searat.nar, Himaruya's Sealand and Latvia ukagaka, featuring other characters such as Belarus. Links to this specific ukagaka are hard to come by so I ran the software through a decompiler so anyone can sniff through it, fix the bugs that pop up, or just learn more about the character via their text documents. This has been transcribed to UTF 8 so people can easily translate the text files for themselves and learn more about the characters, but I will likely upload the original shit JIS files soon.

## Folder Disection

### ghost/master

* Contains the bulk files of interactions between Sealand, Latvia, and all but one character. 

### bera

* Contains the Belarus portion of the Ukagaka.


### shell.zip

* Contains the image files for the Ukagaka.
